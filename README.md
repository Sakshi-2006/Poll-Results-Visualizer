# Poll Results Visualizer

A web application built to visualize poll results in a clear and interactive way. The project is designed to present voting data with a polished interface and make it easy to understand trends at a glance.

## Live demo
https://poll-results-visuali-lu4p.bolt.host/

## Features
- Interactive poll result visualization
- Clean and responsive user interface
- Easy-to-read presentation of result data
- Suitable for quick demos and local development

## Tech stack
- TypeScript
- JavaScript
- Frontend web app

## Prerequisites
- Node.js
- npm

## Getting started
1. Clone the repository

   git clone https://github.com/Sakshi-2006/Poll-Results-Visualizer.git

2. Navigate to the project directory

   cd Poll-Results-Visualizer

3. Install dependencies

   npm install

4. Start the development server

   npm run dev

5. Open the application in your browser at the local URL shown in the terminal.

## Production build
To generate a production build:

npm run build
